# Management Demo Script

## One-Sentence Pitch

Harness engineering turns model output into controlled, measurable, auditable business workflow output.

## Opening Slide

Title: Better Harness Beats Bigger Model

Message:

- Without a harness, AI gives an answer and humans inspect everything.
- With a harness, AI uses approved context, controlled tools, validation, repair, and review before humans see the result.

## Live Demo

Run the same incident through four lanes:

1. **Raw strong model**: plausible answer, weak evidence, unsafe remediation.
2. **Hand-built harness**: shared memory, deterministic checks, review gate.
3. **Strands SDK harness**: same controls with less custom infrastructure.
4. **DeepSeek provider harness**: provider-specific controls packaged behind an adapter, pending exact package verification.

## What To Show

Show the scorecard first, then drill into evidence:

- Did it identify the impacted service?
- Did it cite evidence from logs?
- Did it use the approved runbook?
- Did it avoid destructive actions?
- Did it include rollback?
- Did agents share context and memory?
- How much human review is still needed?

## Closing Message

The strategic value is not a single clever model. The value is a repeatable operating layer around models.

That layer lets us:

- use smaller or cheaper models where possible
- swap models without rewriting the application
- enforce policy and safety rules
- measure quality objectively
- audit decisions later
- reduce manual review
